# Electricity bill calculator

## Description
this program compute the user electricity bill.

## Version 1 – Original code without input validation

-Input: Accepts the user's name , previous and current reading.
-Process: Calculates and display the electric consumption and total bill
-Output: Electricity consumption and the total bill
-Does not include input validation.

## Version 2  - The original code with input validation

-Input: Accepts the user's name , previous and current reading.
-Process: Calculates and display the electric consumption and total bill
-Output: Electricity consumption and the total bill
-Includes input validation
